# Fødselsdage og omtanke

En lille agent, der hver morgen tjekker, hvem der har fødselsdag, og hvem det
er tid til at sende en "hvordan har du det / jeg kom til at tænke på dig"-besked
(hver 4.-6. uge, max 2 om dagen). Den skriver udkast, logger dem og sender
en notifikation. Se `CLAUDE.md` for detaljer.

Prøv selv: `python3 scripts/omsorg.py plan`
